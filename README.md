# 単位の感覚

長さ・重さ・かさ・広さの単位を読みかえたり、1円玉の重さやお札の長さから身近な量の見当をつけたりする1日5問のゲーム。押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/tani-kankaku/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・好きなだけ）、解いた種類の「覚えること」と単位の早見が見られる「単位帳」があります。
- まちがえても選び直せます。正解すると「なぜ」と出典が出ます。ヒントは「見るところ」→「選び肢を2つにしぼる」の2段です。
- 数は毎回種から作るので、同じ問題がなかなか続きません。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、記録を別の端末へ移す「引き継ぎ」があります。

## 中身の出どころ

単位の決まりと、硬貨・お札の値は、次の公的な資料で確かめたものだけを使っています。

- [e-Gov 法令検索 計量単位令](https://laws.e-gov.go.jp/law/404CO0000000357)：別表第一（アール＝平方メートルの百倍、ヘクタール＝アールの百倍、リットル＝立方メートルの千分の一、トン＝キログラムの千倍）、別表第四（接頭語：メガ・キロ・ヘクト・デシ・センチ・ミリなど）、別表第五（平方・立方の単位に付けた接頭語は乗数の二乗・三乗）
- [日本銀行 現在発行されている銀行券・貨幣](https://www.boj.or.jp/note_tfjgs/note/valid/issue.htm)：硬貨の重さと直径（1円玉 1.0g・20.0mm など）、お札の大きさ（千円券 76×150mm・五千円券 76×156mm・一万円券 76×160mm）

硬貨とお札の絵はこのゲームで描いた簡単なもので、本物の図がらとはちがいます（大きさの比は本物に合わせています）。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を Google から読み込むとき（保存した文字を確かめ直すときも）、Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
